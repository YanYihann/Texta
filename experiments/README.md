## 运行边界

- 部分脚本使用已登录的 Codex CLI；部分读取本地 `.env` 并请求已配置的模型，可能产生模型费用。
- 早期脚本和浏览器 QA 记录含本机 CLI 路径、固定端口及当时的接口切片位置；复现前应核对环境和当前代码。
- CLI 总耗时包含启动和服务等待，不能当作网站耗时；不同模型和版本的结果也不能直接比较。
- `raw/` 中的提示词、响应和运行事件，`isolated/` 临时目录以及代码快照保留在本地，由 `.gitignore` 排除。汇总报告中的原始轨迹描述需要本地运行后才有对应文件。
- 当前回归检查使用 `npm test`；实验脚本不会自动执行。

生产生成逻辑以 [generation/](../generation/) 源码及 [当前文档索引](../docs/README.md) 为准。
