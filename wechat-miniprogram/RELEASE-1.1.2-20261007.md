# Texta 1.1.2 已上传，待审核发布

默认微信快捷登录；首次自动创建账号，不要求邮箱。需要网页版时可绑定新邮箱，或选择“关联已有账号”，输入原邮箱账号密码，经验证后自动合并收藏、生词、掌握状态和已用额度，沿用原邮箱账号套餐。仅普通免费微信账号且无订单时自动合并；原邮箱已有其他微信、当前微信账号有套餐/订单或资料超限会提示核对。

操作入口：我的 → 账号设置 → 关联已有账号 → 输入原邮箱与原密码 → 同意服务条款和隐私政策 → 验证并合并账号。合并前自动同步本机资料，之后微信直接登录原邮箱账号；原微信账号会话撤销，原账号停用，本机历史迁移并保留旧缓存备份。关联只能由用户主动验证提交，不能仅凭邮箱自动归并。
