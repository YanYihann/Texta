# 关联已有邮箱账号 — 1.1.2

微信快捷登录仍是默认入口。已有 Texta 邮箱用户可在“我的 → 账号设置 → 关联已有账号”输入原邮箱和原密码，验证后自动将当前微信账号合并至该邮箱账号；新邮箱仍在当前用户 ID 上设置登录凭据。

合并收藏、收藏夹、生词、掌握状态、使用记录及每日已用额度；保留原邮箱账号的角色、密码、套餐、永久套餐及有效期。同一单词保留最新状态与最早收录日期，保留删除标记。本机生成历史会并入目标账号，原隔离缓存保留为备份。其他设备未上传的本机生成历史不会跨设备迁移。仅支持当前微信账号为普通免费账号且没有支付订单；付费来源账号、原邮箱已有其他微信绑定或资料数量超限会提示核对，不自动覆盖。

后端采用 Serializable 事务、固定顺序行锁和失败回滚。所有原微信账号会话撤销，向本次密码验证请求签发新的目标账号会话；原邮箱账号既有会话继续有效。原微信用户记录停用并保留合并关系。旧设备缺失学习条目的同步不会删除合并后的云端资料，删除仍按较新标记执行。迟到的额度退款及生成日志按合并关系处理。

验证：小程序 49 项测试、55 文件检查、8 个 WXML 与 9 个 WXSS 编译通过。后端 14 项微信/账号测试及资料 API 测试通过，账单 8 项通过、1 项数据库测试跳过。Prisma validation、server 语法通过。模型替身覆盖密码错误和限流、身份冲突、付费账号保护、数据去重、额度合计、撤销会话、事务回滚及重试。实际模拟器的 API fixture 完成错误密码→成功关联→目标个人页，收藏和生成历史保留，零运行异常，未调用生成接口，原存储状态已恢复。证据目录 artifacts/wechat-merge-20261007/。

真实 PostgreSQL 隔离 schema 测试未能从本机连接数据库，未宣称并发实测通过。真实用户邮箱合并仍需用户在手机输入原账号密码验收；不会读取或收集用户密码到测试报告。
