# 微信直接登录 — 1.1.1

按用户最新要求，默认入口为微信快捷登录。用户同意条款与隐私说明后，点击即可进入；首次自动创建免费 Texta 账号，无需填写邮箱或密码。后续微信登录返回同一用户 ID。邮箱登录作为收起的辅助入口保留。

需要网页端时，在“我的 → 账号设置 → 绑定邮箱”填写未注册邮箱、设置并确认密码。服务端在当前账号上增加登录凭据，不创建第二个用户，不更改资料、用量、角色或套餐。此功能尚未接入邮件验证码服务，不宣称已验证邮箱所有权，与既有邮箱注册保持相同规则。

已经属于另一个 Texta 账号的邮箱会提示冲突，不会覆盖或自动合并两边资料；已绑定邮箱不会被此接口替换。既有邮箱账号可从辅助邮箱入口登录，在微信身份尚未被其他账号使用时添加微信登录方式。已绑定的老账号继续直接登录。
