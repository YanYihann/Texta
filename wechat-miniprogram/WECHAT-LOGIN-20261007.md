# 微信快捷登录 — 1.1.0

后续更新：用户已改为默认微信直接登录、邮箱在设置中按需绑定。本文件保留 1.1.0 历史流程，最新请见 [1.1.1 接入记录](WECHAT-FIRST-LOGIN-20261007.md)。

## 使用方式

首次点击“微信快捷登录”时，若当前微信未绑定，页面会要求先登录或注册 Texta 邮箱账号。核对显示的邮箱后点击“确认绑定微信”；之后可直接用微信登录同一账号，沿用原套餐、额度、收藏和生词本。已登录用户也可在“我的 → 微信快捷登录”中绑定。

所有登录与绑定均需先阅读并同意服务条款和隐私政策。绑定失败不会清除已经登录的邮箱账号或学习资料；已有其他绑定时不会自动覆盖。暂不绑定仍可使用邮箱登录。

## 服务端配置

在 Render 的 Texta 后端服务 → Environment 中设置 `WECHAT_APP_ID=wxc1af567af0505b1e` 与对应的 `WECHAT_APP_SECRET`。密钥不能放入小程序源码或发到聊天里。后端需部署 D:\wku\雅思\单词 中的本次修改，并按已有 Render 构建流程生成 Prisma Client、增加 WechatIdentity 表。

后端接口为 `/api/auth/wechat/status`、`/api/auth/wechat/login`、`/api/auth/wechat/bind`。当前小程序会读取服务端能力；后端未部署或暂未配置时，微信入口不可用，邮箱登录保持可用。

小程序只把临时登录 code 传给 Texta 后端，后端向微信核验并将 OpenID 绑定到经过认证的现有用户 ID。服务端 AppSecret 与微信 session_key 不进入小程序或本地存储；本功能不获取手机号、头像或微信昵称。
