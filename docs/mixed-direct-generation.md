# 中英混合直接生成 A

2026-10-06：按用户反馈，混合模式从极短的密集填词改为以“小明”为主角的完整短篇故事，保留正文直接生成 A 方案和一次请求结构。完整词典另行并行准备并长期复用。先前 DeepSeek V3.2 实测只覆盖旧的极短篇提示词，不能作为本次故事版本的质量或性能实测。

当前完整提示词由 `generation/mixed.cjs` 的 `buildMixedPrompt` 构造，真实请求、正文和报告保存在本地 `experiments/mixed-a-deepseek-2026-10-06/`，实验运行日志不随生产版本上传。

流程：输入校验和去重 → 预留1积分 → 同一次模型请求返回选定义项、标题和带原词/词性/中文义项标记的中文故事 → 校验并进行明确的格式修复 → 最多一次完整重生成 → 代码还原英文词和构造语境提示/runs → 返回学习内容。事件计划在生成时内部完成，不再单独输出 storyPlan。最终失败会退回预留积分。

普通模式中文目标范围为 `max(180,90+10n)` 至 `max(280,140+15n)` 字，短文模式为 `max(110,60+7n)` 至 `max(180,100+10n)` 字；n为输入词数。汉字数按词义标记还原为中文释义后统计，不包含 JSON、词表或英文标签。机械校验下限为目标下限的70%，上限为目标上限，给自然表达保留余量。6词普通模式180–280字，12词210–320字；6词短文110–180字，12词144–220字。

已移除“第一句必须含词”“每句2–4词”“最多一两句纯中文连接”和词间固定距离限制。必要的背景、人物判断、复句、过渡和结尾可以完整展开。提示词要求动机→问题→判断及行动→变化→回应开头的结果，避免连续主谓宾流水账、仅列操作、背景堆砌和生僻词义凑主题。程序检查小明是否出现以及整体篇幅，故事合理性和句式自然程度仍需人工审读。

本次仅使用当前对话配置的 Codex 模型测试截图中的11词普通故事和12词短文故事，原始输出保存在本地 `experiments/mixed-story-2026-10-06/`。未调用 Texta 生成 API 或 DeepSeek 服务；Codex 测试耗时不代表网站耗时。

词汇详情与故事并行准备：数据库中已有完整解析的词直接复用，缺失词批量生成并长期保存，两者完成后一起返回。点击只展示已生成的卡片，见 `docs/vocabulary-details.md`。混合例句中文通过本次语境词义在浏览器本地还原，详细词典不会覆盖文章中实际使用的义项。难度选择已移除，快速模式已更名为短文模式；双语文章使用独立的一次生成英中句对流程，见 `docs/bilingual-generation.md`。旧高级生成请求归为普通生成，统一1积分。

这些规则可以限制漏词、篇幅和请求次数，不能自动证明词义选择及故事因果正确。不得用“全部命中”代替内容质量验收。随机难词组的语义质量仍需改进，本次发布用于用户试用，不能视为已确认所有输入都无问题。
