# 中英混合直接生成 A

2026-10-06：按用户要求发布直接生成 A 方案及双语重构版本，供线上试用，同时取消高级生成档位。DeepSeek V3.2 先前实测的覆盖/格式与程序功能检查通过，但随机难词组的故事语义质量仍有问题。

当前完整提示词由 `generation/mixed.cjs` 的 `buildMixedPrompt` 构造，真实请求、正文和报告保存在本地 `experiments/mixed-a-deepseek-2026-10-06/`，实验运行日志不随生产版本上传。

流程：输入校验和去重 → 预留1积分 → 同一次模型请求返回事件简要计划、选定义项和带原词/词性/中文义项标记的中文故事 → 校验并进行明确的格式修复 → 最多一次完整重生成 → 代码还原英文词和构造语境提示/runs → 返回学习内容。最终失败会退回预留积分。

词汇详情按需加载。混合例句中文通过本次语境词义在浏览器本地还原，详细词典更新不会覆盖文章中实际使用的义项。难度选择已移除，快速模式已更名为短文模式；双语文章使用独立的一次生成英中句对流程，见 `docs/bilingual-generation.md`。旧高级生成请求归为普通生成，统一1积分。

这些规则可以限制漏词、篇幅和请求次数，不能自动证明词义选择及故事因果正确。不得用“全部命中”代替内容质量验收。随机难词组的语义质量仍需改进，本次发布用于用户试用，不能视为已确认所有输入都无问题。
